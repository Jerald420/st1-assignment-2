# AI Reflection

Before using AI, I built a small SmartCare appointment prototype using Python. The program stored patient, practitioner and appointment information and used a list, dictionary and functions to book and display appointments. I also added a basic check to prevent an empty patient name.

Copilot helped me understand the purpose of the different parts of the program and identify limitations, such as the lack of duplicate appointment checking and permanent storage. Copilot also provided a simpler alternative implementation, which allowed me to compare different approaches.

Copilot made some assumptions about how an appointment should be represented, such as using a dictionary containing the patient, practitioner and appointment time. I did not automatically accept these suggestions. I checked the code by running the program with normal and unusual inputs, including a blank patient name, duplicate practitioner and appointment time, and None values.

The remaining engineering work includes deciding which requirements the clinic actually needs, improving validation, preventing conflicting bookings, and eventually considering how appointment data should be stored. Copilot can help with understanding and suggestions, but the engineer still needs to verify the output and decide whether it meets the requirements.
