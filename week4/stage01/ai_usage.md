# AI Usage

## AI Tool

Microsoft Copilot

## How I Used AI

I used Copilot as a programming tutor while developing the SmartCare prototype. I asked it to explain the Python code, identify limitations, and suggest possible improvements rather than asking it to replace the whole program.

## What Copilot Helped With

Copilot helped me understand how the appointment data was stored and processed. It also identified limitations in the prototype, including:

- No permanent storage
- No duplicate booking prevention
- Limited input validation

Copilot also suggested a simple function for creating an appointment using a dictionary.

## How I Checked the AI Output

I did not assume that the AI suggestions were automatically correct. I ran the program and tested different inputs, including:

- A normal appointment
- A blank patient name
- A duplicate practitioner and appointment time
- A `None` value

I compared the results with the SmartCare requirements and modified the program where appropriate.

## What I Learned

Using AI helped me understand different ways to implement the same functionality. However, I still needed to test the code, identify assumptions and decide whether the suggestions actually met the requirements of the SmartCare system.
